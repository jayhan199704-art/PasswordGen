# Password Forge（密码生成器）

一个**纯静态**的密码生成网站：在浏览器本地生成强密码，支持长度/字符集/排除规则/强度提示，并提供一键复制。

## 功能
- **安全随机**：使用 Web Crypto `crypto.getRandomValues`（不使用 `Math.random()`）
- **可配置**：长度（8–128）、数量（1–20）、字母/数字/符号
- **规则**：排除自定义字符
- **体验**：强度估算、单条复制/复制全部、显示/隐藏、错误提示、清空结果
- **隐私**：不上传、不保存密码明文（无后端）

## 运行方式
### 方式 A：直接打开（最简单）
直接双击打开 `index.html` 即可使用。

> 说明：部分浏览器在 `file://` 场景下对剪贴板权限更严格；若“复制”失败，建议用方式 B。

### 方式 B：本地静态服务器（推荐）
在项目根目录运行任意一种：

```bash
python3 -m http.server 5173
```

然后访问 `http://localhost:5173/`。

## 快捷键
- **Ctrl/Cmd + Enter**：生成密码
